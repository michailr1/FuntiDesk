01 / MEET FUNTIDESK

One screen.
Many ways to help.

Remote control, calls, files and a terminal. Recent devices, favourites and family, all within reach.

01

Help your family

See their screen, fix settings and explain what to click. Family members can request help with one button.

02

03

Call home

Voice and video calls right in FuntiDesk. The camera starts after the call is answered; automatic answering is a separate owner-controlled setting.

02 / FOR FAMILIES

Pair once.
Then just help.

Pair computers using a six-digit code displayed on screen. Give them familiar names, such as “Mum” or “Holiday laptop”.

  • “Request help” notifies the person you choose.
  • Remote control, files and terminal access follow the permissions you set on your own computer.
  • Calls must be answered. Removing a family member removes the pairing on both computers.

Only add people you trust: family access can work without a password or confirmation. Set permissions in the app.

03 / FOR THE PERSON WHO HELPS EVERYONE

All your computers.

Device status, resource usage and maintenance tools, without opening the remote screen.

OVERVIEW

Check resource usage, hardware details and alerts about full memory or disks.

MAINTENANCE

Fix common problems

End a frozen process, restart a service or disable an unnecessary startup entry.

CONNECTION LOG

Review the history

See who connected and when. Administrative actions are recorded on the remote computer.

See process management

Background maintenance requires access you already have without confirmation: a family pairing or a saved permanent password. It does not grant additional permissions. Viewing multiple screens inside the workspace is still in development.

04 / FILES AND EVERYDAY TASKS

Files, just like
File Explorer.

Transfer documents without opening the remote screen. Folders, photo thumbnails and familiar keyboard shortcuts.

UPDATES

Update with one click

Get the latest release in About, with SHA-256 verification. Your ID and settings stay the same. You can also update the other computer from a session.

ACCESS

Come back after a restart

The installed version with the Windows service supports the sign-in screen and administrator windows after requesting elevation.

WAKE-ON-LAN

Wake your home PC

Send a Wake-on-LAN request through an online computer on the same network. The target needs compatible hardware and BIOS and network adapter settings; a wired connection is usually required.

05 / YOUR FIRST CONNECTION

Start with two devices.

  1. Launch FuntiDesk

    On the Windows computer you want to access. For ongoing help, install the app with its service.

  2. Share the ID and password

    Privately, with someone you trust. Your helper opens the app or web console and enters those details.

  3. Add to family

    If you help regularly, pair the computers using a code and set permissions. You will not need to share a password every time.

From your phone, in a browser

07 / TRUST AND CONTROL

Your connections.
Clear access rules.

Open-source code and FuntiDesk infrastructure. Direct connections between devices or the project’s relay server.

No silent fallback to another server

The server address and its key are pinned in the client. If the infrastructure is unavailable or authentication fails, no connection is established.

The owner controls access

Use a temporary password, permanent access or family permissions. The camera starts after answering, unless the owner explicitly enables automatic answering.

History stays on the device

The connection log is stored on the computer itself: sessions, file transfers and rejected attempts.

QUESTIONS AND ANSWERS

Before you connect.

Do I need an account to connect?

To connect with an ID and password, use the app or web console. Your account is for devices and list synchronisation. Signing in does not replace the computer’s password or access permissions.

How do I call my family?

Choose a device in the app and click Call. The other computer receives an incoming call. Voice, answering and ending calls have been tested; two-way video on two physical computers with cameras still awaits testing.

Can I help when nobody is at the computer?

Yes, if the owner has set up family or permanent access in advance. Install FuntiDesk with its Windows service for access after restarting and at the sign-in screen. Only add people you trust to your family.

How is the workspace different from a screen session?

It shows status, processes, services, startup entries and connection logs without opening remote screens. Connections require existing permissions. Viewing multiple screens in the workspace is still in development.

What works on Linux, Android and iPhone?

Linux and Android are available as test builds. On iPhone, Safari can control a Windows computer; controlling the iPhone itself is not supported. Windows is the main tested platform. Current status →

Where can I follow updates and report problems?

Find news and guides in the Telegram channel. Report technical problems in GitHub Issues. Do not post IDs together with passwords, access codes or personal information.
