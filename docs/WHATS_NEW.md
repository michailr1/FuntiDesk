# Что нового в FuntiDesk

Этот файл читают люди, а не разработчики: пишем простыми словами, что изменилось для пользователя. Верхний раздел (от первого заголовка `##` до следующего) CI кладёт в релиз файлом `funtidesk-whats-new.txt`; клиент показывает его в окошке «Вышла новая версия» на главном экране (ADR-007). Перед выпуском релиза — добавить раздел сверху. Строки начинаются с «• », без разметки Markdown: окошко показывает текст как есть.

## 2026-10-13, права семьи

• Настройки → Семья → «Права»: для каждого члена семьи можно отключить вход без пароля, управление, передачу файлов и терминал или включить «Спрашивать разрешение». Меняется только на этом компьютере; по умолчанию всё разрешено.

## 2026-10-13, дополнение

• Передача файлов: дерево папок само раскрывается до открытой папки и подсвечивает её.
• Кнопка «Обновить» обновляет FuntiDesk в любой папке и FuntiDesk-portable.exe (portable один раз скачайте заново).

## 2026-10-13

• Кнопка «Обновить» теперь обновляет FuntiDesk в любой папке и FuntiDesk-portable.exe. Если у вас portable-версия, один раз скачайте новый FuntiDesk-portable.exe — дальше он будет обновляться кнопкой.
• Передача файлов: слева в каждой панели — дерево папок, как в Проводнике: быстрый доступ, диски и папки со стрелкой.

## 2026-10-12, исправление

• Кнопка «Обновить» снова работает, если FuntiDesk запущен ярлыком из «Пуска». Раньше обновление в этом случае откатывалось и оставалась старая версия.

## 2026-10-12

• Новые настройки: «Общие», «Доступ к компьютеру», «Семья», «Звонки», «О программе». Всё техническое собрано в «Дополнительно».
• В настройках есть вкладка «Семья»: кого переименовать, кого удалить, как добавить новый компьютер.
• О новой версии теперь сообщает окошко на главном экране. Нажмите на него — увидите, что изменилось.
• Окно входящего звонка появляется в центре экрана, поверх всех окон.
• «Постоянный доступ» теперь сразу под паролем, его не нужно искать прокруткой.
• Убраны кнопки входа в аккаунт: их негде было использовать. Свой личный кабинет FuntiDesk — в планах.
