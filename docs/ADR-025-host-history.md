# ADR-025: история компьютера для рабочего места

Статус: **принят 2026-11-13** (решение владельца продукта: вариант 2). Продолжает ADR-024 (этап 9).

## Задача

Администратору нужно видеть не только «сейчас», но и «как было»:
- когда компьютер был включён и в сети;
- нагрузка процессора, памяти и диска за последние сутки или неделю;
- когда он перезагружался.

Сейчас рабочее место показывает только текущие цифры, и только пока окно открыто.

## Варианты

1. **История у администратора.** Рабочее место записывает то, что и так получает раз в 30 секунд, в файл на компьютере администратора.
   - Просто, без изменений на той стороне.
   - Пока окно закрыто, истории нет: «был ли включён ночью» не узнать.
2. **История на самом компьютере** (рекомендуется). Служба FuntiDesk на каждом компьютере раз в 5 минут дописывает в свой файл строку: время, процессор, память, системный диск. Хранится 7 дней, это около 2000 строк и меньше 200 КБ. Рабочее место запрашивает историю по служебному подключению (запрос `history`) и рисует график.
   - История полная, даже если окно администратора было закрыто.
   - Данные не покидают компьютер, пока их не запросил тот, кто может им управлять.
   - Сервер не нужен.
   - «Был включён» — это есть записи; «перезагрузка» — это время запуска системы по счётчику работы.
3. **История на сервере.** Компьютеры сами отправляют показатели на desk.funti.cc, сервер хранит их в SQLite.
   - Видно и выключенные сейчас компьютеры.
   - Но данные компьютеров уходят на сервер и хранятся там: это новое хранилище, новый поток данных и вопрос безопасности.
   - Для семьи и небольшого офиса это избыточно.

## Решение

Вариант 2.
- Файл истории на компьютере: построчный JSON в папке данных FuntiDesk, раз в 5 минут, старше 7 дней удаляется.
- Запрос `history` отдаёт его только тому, кто может управлять компьютером (как остальные запросы ADR-023/024). Отдельной записи в журнале не нужно: это служебное подключение, оно уже записано.
- В «Обзоре» появляется график за сутки или неделю: нагрузка и полосы «был выключен».
- Владелец компьютера может выключить сбор в «Доступе к компьютеру»; тогда файл удаляется.

## Безопасность

- Новых сетевых потоков и серверных хранилищ нет; данные отдаются только по существующему авторизованному служебному подключению.
- В истории нет имён программ, окон и пользователей: только числа нагрузки и время.

## Чего это не закрывает

Состояние компьютера, который выключен прямо сейчас, видно только до момента выключения. Оповещение «компьютер не включался два дня» возможно только по варианту 3.
