# ADR-003: выполнение обязательств AGPL при распространении сборок

Статус: принято как проектная политика

Дата: 2026-09-17

## Контекст

FuntiDesk использует компоненты под GNU AGPL v3. Планируется раздавать готовые сборки владельцу, членам семьи и друзьям.

Для проекта принимается консервативная модель соблюдения лицензии: получатель бинарной сборки должен иметь понятный доступ к соответствующему исходному коду именно той версии FuntiDesk, из которой она собрана, включая необходимые скрипты сборки и модификации покрываемого лицензией кода.

## Решение

Каждый распространяемый релиз FuntiDesk должен иметь:

1. git tag/commit, однозначно соответствующий бинарной сборке;
2. сохранённые тексты применимых лицензий и notices;
3. доступный получателю полный Corresponding Source для покрываемой AGPL части;
4. скрипты и конфигурацию, необходимые для воспроизводимой сборки, кроме стандартных системных инструментов и исключений, прямо допускаемых лицензией;
5. понятную ссылку/указание, где получить исходники соответствующего релиза.

Публичность репозитория упрощает выполнение этой политики, но релизный процесс всё равно должен связывать конкретный бинарник с конкретным source tag.

## Ограничение

Это инженерная политика проекта, а не индивидуальная юридическая консультация. При изменении модели распространения, коммерциализации или добавлении компонентов с другими лицензиями проводится отдельное лицензионное ревью.

## Критерий релиза

Бинарная сборка не считается готовой к передаче третьим лицам, пока для неё не опубликован/доступен соответствующий исходный код и license notice.
