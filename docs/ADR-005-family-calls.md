# ADR-005: Звонки вместо «Посмотреть камеру»

**Статус:** принято владельцем 2026-10-08. Этапы 1 и 2 реализованы и проверены на двух компьютерах 2026-10-08 (`docs/reviews/2026-10-08-pr12-windows-acceptance.md`).
**Дата:** 2026-10-08.
**Связано:** `docs/ROADMAP.md` (M4: «Попросить помощи», «позвонить домой»), `docs/SECURITY.md`, ADR-004.

## Проблема

Сеанс «Посмотреть камеру» включает веб-камеру чужого компьютера, если звонящий знает ID и пароль. Человек у компьютера ничего не подтверждает. Для семейного продукта это неожиданно и небезопасно: одноразовый пароль диктуют для помощи с компьютером, а не для того, чтобы на тебя смотрели.

Владелец 2026-10-08 решил превратить сеанс камеры в семейный видеозвонок.

## Решение

Сеанс камеры в интерфейсе FuntiDesk называется «Позвонить». Звонок нужно принять на той стороне.

**Этап 1 — без изменения протокола.**

- Звонящий: «Позвонить» на главном экране и в меню устройства открывает сеанс камеры; после входа клиент сам запрашивает голосовой вызов (upstream `VoiceCallRequest`).
- Абонент: верный пароль только вызывает звонок. В окне FuntiDesk появляется «Входящий звонок…» с кнопками «Ответить» и «Отклонить»; камера включается после «Ответить» (upstream `ipc::Data::Authorize`, как в режиме подтверждения нажатием). Голос в отвеченном звонке включается без второго подтверждения. Окно звонка не сворачивается: в нём кнопка завершения.
- Звонящий, пока абонент не ответил, видит upstream-сообщение «Дождитесь, пока удалённая сторона примет запрос».
- Настройка «Отвечать на звонки автоматически, если звонящий знает пароль» (`funti-call-auto-answer`) в «Безопасности». По умолчанию выключена. Включается только строгим `Y`, любое другое значение означает «нужно ответить» (fail closed). При автоответе камера включается по паролю, как раньше, а голос по-прежнему подтверждается на той стороне.
- Пароль для звонка пока нужен: семейных контактов ещё нет (этап 3).
- Остальные сеансы (управление, файлы, терминал) не меняются.

**Этап 2 — двустороннее видео** (решение владельца 2026-10-08: менять протокол). Ядро upstream передаёт камеру только от абонента к звонящему. Абонент видит звонящего через встречный сеанс камеры, открытый автоматически:

- после ответа клиент звонящего берёт у своей службы одноразовый uuid (IPC `FuntiCallBackRequest`, срок 30 секунд) и отправляет его абоненту новым сообщением `Misc.funti_call_back_request` (поле 1001; номера от 1000 зарезервированы за FuntiDesk, чтобы не пересечься с upstream);
- служба абонента принимает его только в авторизованном сеансе камеры и открывает у себя окно «Позвонить» к звонящему с этим uuid (как upstream «сменить стороны», но исходный сеанс не закрывается);
- служба звонящего пускает встречный сеанс по uuid без пароля и без ответа, только если это сеанс камеры и камера разрешена; любой другой тип сеанса с этим uuid закрывается (fail closed). Uuid одноразовый и привязан к ID абонента;
- встречный сеанс сам не запрашивает голос и не просит встречного видео (голос уже идёт в основном сеансе);
- клиент, который не знает нового сообщения, его игнорирует: звонок остаётся с видео в одну сторону.

Сервер `hbbs`/`hbbr` содержимое сообщений не разбирает и не меняется.

**Этап 3 — семейные контакты.** Звонок без ID и пароля: разовое сопряжение устройств и уведомления через инфраструктуру FuntiDesk. Тот же механизм нужен «Попросить помощи» (ROADMAP M4); оба сценария проектируются одним ADR, без второго канала уведомлений.

## Последствия

- «Просто посмотреть камеру» без участия человека (проверить дом, пока никого нет) по умолчанию недоступно; владелец компьютера включает это сам настройкой автоответа.
- Звонок, отвеченный один раз, переподключается без повторного ответа в пределах upstream-окна «недавнего сеанса» (обрыв связи).
- Одно «положить трубку» завершает весь звонок: клиент при завершении сеанса камеры просит свою службу закрыть сеансы камеры от этого собеседника (IPC `FuntiCallEnded`), служба закрывает их с причиной `funti-call-ended`, окно на другой стороне закрывается без сообщения об ошибке.
- Мелодии входящего звонка в этапе 1 нет; окно выходит поверх остальных.
- Требование ответа работает на стороне абонента: если у абонента старая версия FuntiDesk, камера включится по паролю, как раньше.
