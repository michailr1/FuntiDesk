# Двухпанельный менеджер файлов (#67)

По запросу владельца: «Это устройство» и «Удалённый компьютер», desktop — рядом, телефон/низкое окно — вкладки с клавиатурной навигацией. Выделение отдельно от передачи, явные «Отправить →»/«← Скачать», целевая удалённая папка показана перед отправкой. Локальный выбор сохраняется при удалённой навигации; устаревший удалённый выбор сбрасывается при смене папки/списка. Поиск на обеих сторонах, папки первыми и размеры/значки сохранены. Протокол/пароли/лимиты 50 МБ/запрет перезаписи не менялись. Новых зависимостей, серверов и хранилищ нет.

Локальная сторона показывает выбранные пользователем File, либо содержимое выбранной папки через прогрессивный [showDirectoryPicker](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker): только `read`, по нажатию, с проверкой наличия API. Safari/неподдерживаемый браузер предлагает выбор файлов. Читается только текущая папка (до 10 000 записей, метаданные пакетами по 32), без рекурсивного обхода; выше выбранного корня перехода нет. Скачанное сохраняет браузер, не выбранная локальная папка. File/handles не пишутся в постоянное хранилище; закрытие/смена владельца инвалидирует pending picker/metadata и очищает ссылки/выбор/Blob URL.

Проверки: 21 unit/native-crypto тест, включая явный локальный выбор/очистку, отсутствие рекурсивного чтения/выхода выше корня, отказ разрешения и поздний ответ после закрытия. Зашифрованный браузерный fixture проверяет отсутствие передачи при выделении, явные upload/ACK/download bytes, локальный выбор нескольких файлов и выбор одного, сохранение выбора при удалённой навигации, конфликт/отмену/права, mocked directory picker/read mode/навигацию, отсутствие API, поздний file picker после закрытия. Layout и доступность действий — 320/390/844 px, desktop 1280 px; снимки просмотрены. Полный прежний видео/телефон/reload сценарий также проверяется. Поставка — только console-only из main с сохранением главной/кабинета/API v4, фактический источник и откат в PR. Это fixture/Chromium, не настоящая приёмка iPhone/Windows или системного directory picker; #67 остаётся открыт.
