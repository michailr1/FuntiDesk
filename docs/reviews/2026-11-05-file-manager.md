# Менеджер файлов в Windows-окне: меню, клавиатура, открытие файлов, миниатюры (#99–#105)

Запрос владельца 2026-11-03: в окне передачи файлов не работала правая кнопка, нужны копирование, удаление, переименование и «юзер френдли» работа. Список улучшений согласован владельцем по пунктам; миниатюры — ADR-017 (вариант Б). Принято владельцем 2026-11-05 после проверки сборки на двух компьютерах.

## Как проверено

- `dart analyze` изменённых файлов — без новых замечаний на каждом этапе (сравнение с исходными файлами).
- `funti_thumbnail.rs` — тесты в модуле, собранные отдельно с `image =0.24.9`: EXIF в обоих порядках байт, размер и поворот, прозрачность, отказ для мусора, папки, не-картинки и заголовка на 100 000 × 100 000. Фото 24 Мп — 0,4 с.
- Протокол — отдельная сборка `protobuf-codegen 3.7.2`: новые сообщения кодируются и читаются, схема без поля 1001 разбирает его без ошибки.
- CI по всем PR — зелёный. Windows-сборка `R21 Windows clean build` (run 41722579507, коммит `db96ef52`, все изменения стопки) — успешна; релиз не публиковался.
- Живая проверка владельцем на двух компьютерах с этой сборкой — принято 2026-11-05.

## Известные ограничения

- Копирование внутри одного компьютера не поддерживается протоколом.
- Перетаскивание из Проводника идёт прежним путём, с вопросом про каждый совпадающий файл.
- Миниатюры: HEIC и видео — значок; файлы больше 50 МБ и 40 Мп — значок. С компьютером на старой версии окно после трёх неотвеченных запросов просит обновить FuntiDesk.
- Удаление безвозвратное, без Корзины (пункт 7 владелец отклонил).
- Передача множества мелких файлов (ADR-017, вторая часть) ждёт решения владельца.
