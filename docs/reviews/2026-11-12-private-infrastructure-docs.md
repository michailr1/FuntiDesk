# Граница публичной документации

По решению владельца от 2026-11-12 удалены инфраструктурный ADR и связанные инструкции, шаблон и отдельный сетевой тест. Подробности из текущих отчётов и правил заменены требованиями и результатами на уровне продукта. Номер удалённого ADR повторно не используется.

Перед удалением исходные материалы, включая описания и комментарии прежних задач/PR, сохранены в закрытом документе владельца. Содержимое прочитано обратно и сопоставлено; права проверены — только владелец. Приватные ссылки не опубликованы.

Проверены diff, ссылки и отсутствие обращений к удалённым файлам в CI и компонентах продукта. Работающие сервисы и защита сервера не изменялись; runtime-зависимостей от удалённых файлов нет.

Ограничение: старые коммиты, diff прежних PR и история редактирования GitHub могут сохранять опубликованные сведения. История main не переписывалась. Далее общая инфраструктура сопровождается отдельно в закрытой документации.
