# Файловый экран веб-консоли (#67)

По отзыву владельца переделан UI #86 без изменения протокола/авторизации/лимитов. Телефон: полноэкранный dialog с постоянной шапкой/действиями и одним прокручиваемым списком вместо длинной формы с вложенным коротким списком. Папки/диски первыми и отдельными группами, SVG-значки/стрелки действий, имя отдельно от размера в Б/КБ/МБ. Естественная сортировка имени, обратный порядок/размер/дата; папки всегда первыми. Поиск только в текущей папке. Цепочка пути, «Выше», Домой/Диски/Обновить; ручной путь раскрывается. Отправка — отдельная кнопка системного выбора, подтверждение после выбора; переименование по запросу. Закрытие очищает выбор/поиск/Blob URL. Новых зависимостей/сервисов нет.

Основания: [Apple Lists and tables](https://developer.apple.com/design/human-interface-guidelines/lists-and-tables) — читаемые строки, свойства отдельно, явный переход в иерархии; [Disclosure controls](https://developer.apple.com/design/human-interface-guidelines/disclosure-controls) — второстепенные формы показываются по запросу; [W3C Target Size Enhanced](https://www.w3.org/WAI/WCAG22/Understanding/target-size-enhanced) — собственные цели касания от 44 CSS px. Это применение рекомендаций к FuntiDesk, не копирование платформенного UI.

Проверки: unit-тесты сортировки/групп/чисел/регистра/неизменности native-порядка и размеров; подписанный зашифрованный browser fixture сохраняет upload/ACK, download bytes, конфликт, отмену, неверный пароль/ключ и отзыв права. Дополнительно — поиск/пустой результат, папка/выше/цепочка, недоступный большой файл, скрытые формы, 320/390/844 px и доступность списка/кнопки отправки. Скриншоты просмотрены локально. Реальные iPhone/Windows ещё требуют проверки владельцем; #67 открыт. Поставка только console-only по существующей инструкции, с сохранением главной/кабинета/API v4; фактический источник/проверки/откат записываются в PR.
