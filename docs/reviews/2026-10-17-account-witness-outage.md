# Недоступность кабинета: отключён независимый witness

Эксплуатационные сведения об общей инфраструктуре и других узлах перенесены в закрытый архив владельца; здесь сохранены доступные сведения о проверках продукта.


Дата проверки: 2026-10-17. Пользователь сообщил ошибку «Кабинет сейчас недоступен» в Windows.

## Установленная причина

- Core API и witness-relay запущены с прежними проверенными образами, без рестартов. В журнале API повторяется `account database maintenance failed`.
- Архивная цепочка проверена по HMAC всех 16 records, digest последней зашифрованной копии совпал. Архивный Head revision 19 целиком совпадает с последней подтверждённой отметкой Core; машинный ключ совпадает. Текущая основная revision — 21, её нельзя объявлять подтверждённой до связи с witness.
- Архивный TLS-сертификат действует до 2026-12-03. Отказ вызван отсутствием работающего сервиса, а не истечением этого сертификата.

Статические `/account/` и bootstrap отвечают `200`, запросы session/library без токена — `401`; это не доказывает готовность авторизованных операций. При необходимости независимого подтверждения кабинет отказывает по ADR-011, вместо публикации неподтверждённых результатов.

## Следующее действие


В рамках диагностики выполнены только чтения; рабочие конфигурации, данные и контейнеры не изменялись. Живое исправление и повторная проверка кабинета ещё не выполнены.
