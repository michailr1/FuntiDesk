# FuntiDesk · Живые соединения

Отдельный экспериментальный сайт: публичная продуктовая страница и интерактивная симуляция интерфейса. Эталонная эмблема взята из michailr1/FuntiDesk, ветка michailr/funtidesk-web, web/assets/funtidesk-mark.svg.

Соединения, смена сети, удалённый экран и передача файла симулируются в браузере. Production-инфраструктура не используется. iOS обозначен как концепт с входящим просмотром. Скачивание ведёт на страницу GitHub Releases без обещания наличия релиза.

Статические HTML/CSS/JS без сборки: python -m http.server 8080 --directory dist.

Основная анимация: canvas, частицы из растровой маски текста превращаются в сеть с линиями и пакетами. Есть пауза и поддержка prefers-reduced-motion. Проверить ширины 390 и 1440, переключение устройств/маршрутов, отмену подключения и смену сети.

## Интерактивная среда v2

Рабочий стол: блокнот с вводом, ограниченный терминал (help/status/clear), перемещение и закрытие окон, режим управления/просмотра, разворачивание экрана. Сеть: анимированные пакеты, графики демонстрационных показателей, регуляторы скорости и потерь, перекрытие P2P, обрыв и восстановление сети. Передача файлов зависит от моделируемой скорости и останавливается при обрыве. Для своего файла читаются только имя и размер; содержимое не читается и не отправляется.
